### 命题逻辑系统的组成

**10:05**

首先要有东西来表示每个变量是做什么的，这叫作命题变量。命题变量之间要连接，所以需要命题联结词。联结词要有语义，语义就是真值表。那如果想连接更多的命题表达式，就需要有一个合法的方式，这叫作合式公式（WFF）。有了这些东西之后，要把一个合式公式转换成另外一个合式公式，就要用等值定理，也就是研究哪些命题逻辑表达式互相等价，这是另一部分内容。

### 求解、范式与 CNF

**10:47**

学完等值定理之后，我们学习如何用计算机自动求解一个命题逻辑表达式。求解它有什么性质呢？有永真、矛盾，还有可满足。为什么不能用真值表求解呢？可以用，没有问题，但是太慢了，复杂度太高。所以要用计算机算法。算法首先要把公式变成一个统一的式子，也就是范式，我们选 CNF。为什么选 CNF？有一个开销方面的考虑。只要引入辅助变量，转换后的公式和原公式在可满足性上就是一样的。那这里面就有一个问题。

### 可满足等价与解

**12:05**

所谓可满足性等价，是说 A 和 B：如果 A 可满足，B 也可满足；如果 B 可满足，A 也可满足。但是使它们可满足的解不一定相同。这里面就有个问题。上次付宇轩同学就问过这个问题，他说懵了：我把原式转换成一个可满足等价的式子，但两个式子的解不一定一样。那我怎么信任这个解？我之前说过，你要拿 solver 去求解出来那个解，就可以作为 counterexample 扔进去，它就是一个错误的答案。既然可满足不等价，那它的解是不一样的，对不对？可满足等价是说它们俩可满足性等价，但这两个式子的解不一定是相同的。把 A 转成这个，我觉得是非常好的一个问题。我教了这么多年，终于有学生敢于挑战这个事情了。

### 程序正确性验证中的反例

**13:17**

这个是一个很自然的问题：我把这个式子转换成了一个跟它解不一样的式子。那我求出来的那个 counterexample，也就是我求出来那个赋值，使得这个式子可满足，它能不能用？我们逻辑上要证明一个程序是正确的，怎么证明？要证明这个程序永远能推出这一点。然后取反，证明它是矛盾。如果求解出这个矛盾式是可满足的，那就说明有 bug。那我通过可满足性等价，把式子变成另外一个式子；虽然它们俩可满足性等价，但是如果求出的解不一致，那我能不能用可满足等价和转换后的解来生成它的 counterexample 呢？不能。有没有反应过来？

### 可满足等价的澄清

**14:11**

今天让大家复习的目的，就是我想把这个知识点再讲一下：可满足等价是指什么。大家记得吧？当然你可以自己算一下，这两个式子是不是可满足性等价。可满足等价是说：一个式子可满足，另一个也可满足；另一个可满足，这个也可满足。但是使它们俩可满足的解不一定一样。如果解完全一样，那么它们就不叫可满足等价，而叫等价。那如果有一个值，我是从这个式子转到另一个式子；如果有一个值使得转换后的式子可满足，那我能用这个值作为 counterexample 吗？不能，因为它不是原式子的解。那为什么在这里我们就可以做这件事情呢？大家想想为什么？

### 上下式子的可满足性

**15:24**

对，上面的那个式子是可满足的。下面那个式子一定可以找到某一个赋值，让它也可满足。那就是说，如果上面这个式子可满足，比如 p 为真或者 q 为真，那么我一定能找出一个 z 使得它可满足。反过来，如果有一个值使得下面这个式子可满足，那么上面这个式子一定也是可满足的。

### 可满足性转化不是简单等价

**16:21**

这两个式子不是简单的可满足性等价，而是具有单向性质：如果有一个赋值使其中一个式子可满足，那么倒推回去，也能使原来的式子可满足。具体地说，如果这个式子可满足，那么其中某些条件必须成立，例如 \(p\) 和 \(q\) 中至少有一个为 true；若 \(z\) 为 true，则 \(p\) 一定为 true；若 \(z\) 为 false，则 \(q\) 一定为 true。因此，虽然这个转换看起来涉及可满足性等价，但实际上有一个很好的性质：通过转换后的式子求出一个解，使该式子可满足，倒推回来也能使原来的式子可满足。

因此，如果让这个式子可满足，也就是把程序正确性转换成这样的式子，求出一个赋值使式子可满足，就可以用来做可满足性求解。这个问题比较绕，但非常重要；之前几届没有人问过，所以没有讲过，既然有同学问了，就在这里说明：两个式子不是简单的可满足性等价。更准确地说，如果有一个解使其中一个式子可满足，那么一定也能使另一个式子可满足；但反过来不一定。反过来，假设有一个解使某个式子可满足，例如 \(p\) 为 true、\(q\) 为 false，那么可以选取 \(z\) 为 false，使另一个式子不可满足。所以二者不是可满足性等价，而是单边的；最后从这个式子转化到那个式子没有问题。

### 回顾：范式与求解器

**20:13**

回顾一下：我们讲了开关变量，开关变量使得 DNF 转 CNF 比 CNF 转 DNF 简单，复杂度降低，因此最终选择了 CNF。选择 CNF 之后，还讲了主析取范式（PDNF）和主合取范式（PCNF），它们都是唯一的。还讲了真值表和 DNF、CNF 的关系：通过输出为 true 的行构建 DNF，也就是主析取范式 PDNF；通过输出为 false 的行构建 CNF，也就是主合取范式 PCNF。接下来要设计一个求解器，能够求解这样的命题逻辑表达式，于是学了 DPLL 算法。

### DPLL：猜与推

**21:16**

DPLL 算法的基本思想是猜和推。猜就是猜一个变量的值。比如刚开始假设 \(a\) 为 false，根据这个假设推 \(b\)，推不下去；再试 \(b\) 为 true，也推不出来，于是试 \(b\) 为 false；根据 \(b\) 为 false 可以推出 \(c\) 为 false。如果这条分支有问题，就回溯，改猜 \(a\) 为 true。每个变量只有 true 和 false 两种取值，最多猜两次，所以第二次就能把它猜完。因此，猜的过程对应决策变量（decision variable），每一次猜就是一次决策。

猜完之后还要推。推理规则包括单元传播（unit propagation）：一旦猜了某个变量，必须保证每个子句都为 true，并据此继续推导。此外还有纯文字规则：如果某个变量在所有子句中都只以同一种形式出现，而没有它的否定形式，那么可以直接把它赋为 true，无需再猜。

### CDCL 的传播示例

**23:30**

我们的算法里用的就是 CDCL。其基本思想是：假设有一个复杂表达式，先猜 \(x_1\) 为 true；根据 \(x_1\) 为 true，可以推出 \(x_2\) 必须为 false，同时可以推出 \(x_3\) 必须为 true；再根据 \(x_3\) 为 true 推出 \(x_4\) 必须为 false；然后根据 \(x_2\) 为 false 和 \(x_4\) 为 false，推出 \(x_5\) 必须为 true。

### 继续 DPLL 的推导：出现矛盾

**24:24**

沿着这棵决策树继续往下推。按这个子句推完之后，如果发现剩下的推不下去了，就继续猜：假设同时猜 \(x_6\) 为 false，那么根据 \(x_6\) 为 false 和 \(x_5\) 为 true，推出 \(x_7\) 为 false；再由 \(x_7\) 为 false 和 \(x_2\) 为 false，推出 \(x_8\) 为 true。

根据 \(x_8\) 为 true 推出 \(x_9\) 为 false，再由 \(x_9\) 为 false 继续往下推，得到 \(x_{10}\) 为 false、\(x_{11}\) 为 true（这里老师先说成 \(x_{10}\) 为 true，随后纠正过来），接着推出 \(x_{12}\) 必须是 false。于是 \(x_{11}\) 为 true、\(x_{12}\) 为 false，这里就出现了一个矛盾。

### 把导致矛盾的条件写成子句

**25:43**

这就是 DPLL：画出这张图之后，还可以进一步做。既然这个子句已经推过了，就可以把导致这次猜测错误、出现矛盾的那个条件，变成公式中的一部分。变成公式的一部分之后，下一次就相当于告诉 DPLL：不用再去推这个条件了，因为在这个条件下面它已经会产生矛盾。

那什么叫条件？这里有哪些决定性的条件？\(x_1\) 为 true、\(x_6\) 为 false 就是一个决定性条件，只有 \(x_1\) 为 true 是不够的。所以这里可以并上一条子句：\(x_1\) 为 false 或 \(x_6\) 为 true（老师先说成“\(x_1\) 为 true 或 \(x_6\) 为 false”，随即纠正为反过来）。也就是说，必须保证 \(x_1\) 为 false 或 \(x_6\) 为 true，这条子句才成立。

### 其他可以并进来的条件

**27:19**

还有没有其他条件？\(x_8\) 可不可以？\(x_8\) 是不是一个导致矛盾的条件？出现矛盾的原因是：\(x_1\) 和 \(x_6\) 推出 \(x_7\)，使得 \(x_8\) 必须为 true，而 \(x_8\) 必须为 true 最后推出了矛盾。所以可以知道 \(x_8\) 一定不能为 true，也就是可以并上一条 \(x_8\) 为 false。类似地，也可以取 \(x_2\) 为 true 或 \(x_7\) 为 true 这样的条件。

### 怎样切出合法的学习子句

**28:06**

那怎么决定选哪一个呢？有时候用子句最少的，也可以用一些其他条件。核心问题是哪些子句是合法的：在这张图上，找到最后一个决策文字（decision literal），在它右边切一刀、画一条线，这条线里面路径上的这些变量，就可以组成一个学习子句（learned clause，即学习到的子句）。

### 切法与可满足性

**28:47**

这样的切法并不唯一，可以切很多刀，也不必保证切出来的这些子句彼此等价；我只需要保证，只要这些子句存在，这个式子就一定不可满足、一定会出现矛盾。把这些子句学出来之后放到式子里，求出来的可满足解一定是没有问题的：因为我是不断并进新的子句，相当于给公式更多的约束条件，所以求出来的可满足解也会使得原式是可满足的。

整个过程就是这样：在这里我们可以画一刀，再画一刀，得到一个学习子句，其中涉及 \(x_2\)、\(x_5\)、\(x_6\)，即 \(x_2\) 为 true，或 \(x_5\) 为 false，或 \(x_6\) 为 true。划一刀之后，把这一刀对应的变量取出来做成一条子句。

### CDCL：冲突驱动子句学习

**30:26**

这就是我们要学的 CDCL（conflict-driven clause learning），也就是你们在 lab 里会用到的算法，是一个非常简单的 procedure：我基于 DPLL，学到子句之后切一刀，把学到的子句放回公式里，使得新的推进更快，不用再走重复的路。

比如刚才那条 \(x_8\)：在再去猜其他值的时候，很可能也会推出 \(x_8\)；而一旦把 \(x_8\) 这条子句加进去，我就知道相应的取值不需要再去试，或者加一条 \(x_8\) 为 false 这样的提示就可以了。它首先带来更多的约束条件，减小搜索空间。

那么推理是什么？推理本质上就是公理系统：用数学方法构建一套规则，告诉我们一个程序……

### 为什么要引入公理系统

**32:30**

接下来要解决的问题是：如何给出一个算法，根据一些命题逻辑表达式推出另外一些命题逻辑表达式。这有什么用？后面会学到，当程序里面有 while 循环时，就必须构建一个公理系统，使得它可以处理 while 循环。之前我们展示过如何把程序转换成表达式，其中有一个搞不定的就是 while 循环，所以从这里开始铺垫。大家先学习公理系统，到最后一部分讲完贝斯问题、讲到霍尔逻辑的时候，我会给大家看一个公理系统的例子，用它来求解带有 while 循环的问题。

### 公理系统与 Lean

**33:30**

公理系统本身是让我们用形式化的方法来写证明，保证这个证明是对的。其实大家现在就在用 Lean：一直用 Lean 尝试写一些数学，用 Lean 的语言写数学证明，然后再用 Lean 进行求解。Lean 本身就是一套系统，因为它自己提供了一整套离散数学的基础，所以有自己的求解器可以求解。我们现在学的这个公理系统，用来做的就是推导这件事；我们要学习一种方法，通过数理逻辑的形式把一个证明写出来，这在程序验证里面也会有帮助。

### 公理系统的组成

**34:28**

公理系统或者推导分为两个部分：第一部分叫做公理或者假设。它为什么叫系统？因为除了公理和假设之外，还有一系列推理规则。这些推理规则基于公理和假设，可以推导出整个系统中其他规则。所以我们把它叫公理系统：只有公理还不够，还要有推导公理的规则。

用 Lean 写定理、证明的时候其实就是这样：它会先创建一些公理，然后按照 Lean 的方式；Lean 其实也是一种形式化数学的语言。它自带一些推理规则，再根据这些推理规则推出更多定律，然后用 Lean 的 kernel 来证明推理规则是对的，这就是 Lean 做的事情。所以现在数学家也在向这个方向靠拢。那么这就是规则。

### 推理形式与分离规则

**35:47**

具体的形式是什么？我们从最简单的推理形式说起。在公理系统里面，推理形式就是如何根据两个假设推出一个新的结论。比如：如果生病就不去学校，这是第一个命题；第二个命题是我生病了；这两个加在一起就能推出我不去学校。用抽象命题表示：令 a 表示我病了，b 表示我不去学校，那么“如果我病了，我就不去学校”就是 \(a \to b\)。并且我真的病了，即 a 成立；于是 a 成立并且 \(a \to b\) 成立，就能推出 b 成立。这就是我们要讲的第一个推理形式。

手写时，可以这样写：中间画一条横线，横线上面写两个假设，下面写结论。一个前提是 a，另一个前提是 \(a \to b\)，结论是 b。这条推理规则就是：a 成立并且 \(a \to b\) 成立，能推出 b 成立。

怎么证明这件事？用真值表。只要证明它是永真式就可以了。它的确是一个永真式：当 a 为真，并且 \(a \to b\) 为真时，b 必为真。

### 重言蕴含及其性质

**38:03**

刚才这个式子是永真式。现在我们重新定义一个新的符号，它不是命题逻辑连接词，而叫做重言蕴含。它表示两个命题逻辑表达式之间的推理关系：如果 \(a \to b\) 是永真式，就说明 a 能推出 b。我们引入一个新符号 \(a \Rightarrow b\)，即 a 重言蕴含 b。它的意思是：若 a 为真，则 b 必须为真；也就是说，a 为真能推出 b 为真。

记住它不是命题逻辑表达式；它与命题逻辑表达式中单箭头的关系是：\(a \land (a \to b) \Rightarrow b\) 等价于 \(a \land (a \to b) \to b\) 这个式子是永真式。

重言蕴含还有哪些性质？第一，如果 \(a \Rightarrow b\)，且 a 是永真式，那么 b 也一定是永真式。第二，如果 \(a \Rightarrow b\) 且 \(b \Rightarrow a\)，那么 a 和 b 等价。第三，传递性：如果 \(a \Rightarrow b\)，\(b \Rightarrow c\)，那么 \(a \Rightarrow c\)。第四，如果 \(a \Rightarrow b\) 且 \(a \Rightarrow c\)，那么 \(a \Rightarrow b \land c\)；因为 a 成立时 b 成立，a 成立时 c 成立，所以 a 成立时 b 和 c 都成立。第五，如果 \(a \Rightarrow c\) 且 \(b \Rightarrow c\)，那么 \(a \lor b \Rightarrow c\)。

回到刚才讲的规则：a 成立且 \(a \to b\) 成立推出 b。换一个写法，用真值表来看，就是 p 成立且 \(p \to q\) 成立推出 q。这个规则我们给它起一个名字，叫做分离规则。

### 推理规则：分离规则与三段论

**40:31**

分离规则：由 \(P\) 和 \(P\to Q\) 同时成立，可以推出 \(Q\)。除了分离规则，还有其他同样显然的推理规则：由 \(P\to Q\) 不成立，可以推出 \(P\)；由 \(P\to Q\) 不成立，可以推出 \(\neg Q\)。另外，常用规则还有假言三段论：由 \(P\to Q\) 且 \(Q\to R\)，可以推出 \(P\to R\)。下面用刚讲的推理规则证明三段论。

### 形式证明：从假设推出结论

**41:21**

这个证明类似于用 Lean 写证明，原理一样，只是 Lean 的语法比这里复杂得多。假设要证明 \(R\)：已知 \(P\to Q\) 成立、\(Q\to R\) 成立，并且 \(P\) 成立，用命题逻辑来证明这个结论。

### 按书上的写法构造证明

**41:48**

这些条件都作为假设（assumption）。按照书上的写法，先引入前提，称为前提引入；在公式旁注明为什么要引入某个前提。先把 \(P\to Q\)、\(Q\to R\) 和 \(P\) 引入为前提。期末考试中这部分按书上的写法书写。

由 \(P\) 和 \(P\to Q\)，用分离规则推出 \(Q\)。再把刚推出的 \(Q\) 与 \(Q\to R\) 结合，用分离规则推出 \(R\)。证毕。证明结束时通常会画一个方框；板书中这里少画了一个方框。

### 代入规则与置换规则

**43:52**

还有两个简单的规则。代入规则：对于一个永真式，可以把其中每一处某个命题变量替换成任意命题表达式。例如在 \(P\lor\neg P\) 中把 \(P\) 换成 \(R\lor S\)，得到 \((R\lor S)\lor\neg(R\lor S)\)，它仍然是永真式。置换规则：在命题逻辑表达式中，可以把一个命题替换成与它等价的命题。

### 条件证明规则与公式变形

**44:31**

再看一个更复杂的证明。要证明
\[
\bigl(P\to(Q\to S)\bigr)\land(\neg R\lor P)\land(R\to Q)\to(R\to S)
\]
左边的整体是一组条件，右边是要得到的结论。这个式子不像我们熟悉的形式，因为右边 \(R\to S\) 里多了一个 \(R\)。把重言蕴含展开看，子公式 \(P\to(Q\to S)\) 与 \((P\land Q)\to S\) 等价：\(P\to(Q\to S)\equiv(P\land Q)\to S\)。因此可以把 \(Q\) 移到前面，把要证明的关系转化为 \((P\land Q)\to S\)。这个形式我们不熟悉，而 \((P\land Q)\to S\) 是熟悉的形式：假设 \(P\) 成立，同时假设 \(Q\) 成立，推出 \(S\)。相比只假设 \(P\) 成立而推出 \(Q\to S\)，前者简单很多。因此，对于这样的命题，先引入第一个假设。

### 用条件证明规则完成变形

**47:48**

对左边式子中的每个子句都作为假设引入，例如 \(\neg R\lor P\)。用置换规则把 \(\neg R\lor P\) 化为等价的 \(R\to P\)，以便使用分离规则、三段论等。要证明左边整体推出 \(R\to S\)，等价于把 \(R\) 移到左边，并与已有条件取合取，因此可以把 \(R\) 作为前提条件引入。这个规则叫作条件证明规则。

### 条件证明规则的应用

**48:35**

有了 \(r\) 和 \(p\) 这两个作为前提条件引入，就可以推出 \(p\)。推出 \(p\) 之后，左边这个式子也是一个前提条件，即 \(p \to (q \to s)\) 成立；前面已经知道 \(p\) 成立，于是可以推出 \(q \to s\) 成立。

既然 \(q \to s\) 成立，而 \(q\) 也是作为前提假设引入的，那么就能推出 \(s\) 成立。从第一步到第八步，本质上就完成了这样一个证明。

**49:31**

这个结论就是：由 \(p \land q\) 可以推出 \(s\)，不是由单独的 \(p\) 推出 \(s\)——因为把 \(r\) 移到了左边，这种形式的证明就完成了。又由于有条件证明规则，我用 \(r\) 作为条件证明了 \(s\)，实际上就证明了 \(r \to s\)。

这是顺着证的情形。除了顺着证，也就是正向证明，数学证明还有反证法，后面会讲什么叫反证法。好，休息一下，大家可以到前面拿糖。

### 重言蕴含与蕴含联结符

**09:45**

就是这个符号 \(A \models B\)。当然也有同学问——大家一定要狂轰滥炸地追问助教，虽然助教也有自己的事情，但他就是给大家答疑的，这样我们才能知道大家对哪些地方有问题，我也能让下一届学得更好。那么 \(A \models B\) 和 \(A \to B\) 这两个关系是什么？\(A \models B\) 表示 \(A \to B\) 这个命题是永真式；而 \(A \to B\) 是一个命题联结符，所以 \(A \to B\) 是一个命题。\(A \models B\)，也就是 A 推出 B，表示 A 和 B 这两个命题之间的推理关系：如果 A 成立，根据这个推理规则我就能推出 B 成立。

所以这两个符号实际上是在不同系统下的符号。\(A \to B\) 是命题逻辑这个大的数学系统下面的一个联结符，把两个命题连接之后还是一个新的命题；而 \(\models\) 是在公理系统下面：我要已知有一些 assumption，推出新的定理，推理规则中的推导是在公理系统里面进行的。所以 \(A \models B\) 整个这个式子并不是一个命题，它没有 true 或者 false，它只是表示 A 能够推出 B。

除了这种直接证明，我们还有一种方法。

**11:57**

我如果要证 A 推出 B，可以用规约，也叫反证。如果我要证 \(A \models B\)，也可以先看：\(A \models B\) 说明 \(A \to B\) 这个式子是永真式，而这个式子等价于 \(\neg A \vee B\)。那我取反呢？取反就是 \(A \wedge \neg B\)。所以要证 \(A \to B\) 成立，也可以通过证明 \(A \wedge \neg B\) 为 false 来达到，也就是说这个命题和 B 的否命题不能同时成立。

### 规约式

**13:11**

要证明它，也可以从假设出发。那为什么要这样做？因为我们有一个很好的性质：对于假设，假设我有一个假设 \(C_1\)，我要证明 \(C_1 \wedge C_2\)；如果 \(C_1\) 和 \(C_2\) 能够写成 \(\neg l \to C_1'\) 和 \(l \to C_2'\) 这样的形式，那么我要证明 \(C_1 \wedge C_2\) 是 false，就可以等价地证明 \(C_1' \vee C_2'\) 是 false，这样就把开关变量 \(l\) 直接去掉了，起到一个简化的效果。也就是说，\(C_1\) 可以写成这样一个式子，\(C_2\) 可以写成这样一个式子。

我们管下面这个式子叫作上面这个式子的规约式。我不断地去简化，就可以加快速度。大家想一下为什么？

### 开关变量的反向使用

**16:44**

这不就是 \(\neg l\) 推出 \(C_1'\)、\(l\) 推出 \(C_2'\) 吗？这里又用到了开关变量，而且是反着用的。

如果能把式子写成这种形式，就可以化简成那种形式，因为两者是可满足性等价的。所以要证明上面的式子是 false，只要证出下面的式子是 false，上面的式子就一定也是 false。

上面那个性质是倒着用的：如果下面的式子可满足、能找到一组解，也一定能使上面的式子可满足。这两个式子的性质在这里基本上已经用尽了。今天讲的开关变量，在这里其实就是归结。

### 用归结式证明重言蕴含

**18:05**

举个例子。如果要证明 \((p \to q) \land p\) 重言蕴含 \(q\)，就可以等价地证明 \((p \to q) \land p \land \neg q\) 是 false：把 \(q\) 取反，与前面的式子合取，证明它不成立。

把蕴含消去后得到 \((\neg p \lor q) \land p \land \neg q\)。其中 \((\neg p \lor q) \land p\) 的归结式是 \(q\)——为什么是 \(q\) 呢？把这个式子改写一下再做归结，得到的就是 \(q\)。于是整个式子变成 \(q \land \neg q\)，也就是 false。

所以用归结式一步一步化简，最后就能推出 false。归结是从哪里来的？就是之前的开关变量。为什么可以这样做，先放一放；\(\neg q\) 与 \(q\) 归结，同样得到 false。

### 化成合取范式做归结

**23:12**

我们看这个例子：先把公式化成合取范式

\[ (\neg p \lor q) \land (\neg q \lor r) \land p \land \neg r \]

然后建立子句集：\(\neg p \lor q\)、\(\neg q \lor r\)、\(p\)、\(\neg r\)。要证明它是 false，就用归结法把这些前提条件全部写进来。第一个和第二个子句做归结，得到 \(\neg p \lor r\)；第三个和第五个做归结，得到 \(r\)；第四个和第六个再做归结，就得到空子句。

### 对偶式

**24:31**

对于命题逻辑表达式 \(A\)，如果将其中的合取和析取互换、\(T\) 和 \(F\) 互换，就得到 \(A^*\)，那么 \(A\) 和 \(A^*\) 就互为对偶式。

### 对偶式 A*、A⁻ 及其相关性质

**24:48**

除了 \(A^*\)，还有一个概念记作 \(A^-\)：把 \(A\) 里面所有的命题变元都换成前面加上否定词的变元，得到的就是 \(A^-\)。

\(A^*\) 与 \(A^-\) 之间、以及它们与 \(A\) 之间有一系列性质，例如 \(\neg(A^*) \equiv (\neg A)^*\)；对 \(A^-\) 也有类似的关系，即 \(\neg(A^-) \equiv (\neg A)^-\)。书上第 12、13 页还有相关的证明，大家可以自己看，这些内容在实际中从来没有用到过。

还有一些定理：如果 \(A\) 与 \(B\) 等价，那么 \(A^*\) 与 \(B^*\) 等价；如果 \(A\) 能推出 \(B\)，那么 \(B^*\) 能推出 \(A^*\)。这些都是知识点，需要好好自学。

### 波兰表示法：中缀、前缀与后缀

**25:54**

接下来讲波兰表达式，也就是波兰表示法。我们现在使用的表示法，比如 \(A \wedge B\)，是把符号放在中间：左边一个字母，右边一个字母，非常符合人的阅读习惯。小时候写 \(1+2=3\)，也是把符号写在中间，这非常符合我们的 convention。

但中缀形式并不是最符合计算机的。对计算机来说，下面这种形式反而更自然：先写符号，再写操作数。例如写 \(>\ a\ 10\)：先写大于号，因为大于号是二元运算符，计算机就知道后面紧跟着两个操作数，要做的是大于比较。用一个栈来做计算，先 pop 出大于号，再 pop 出两个值，把 \(a\) 与 10 比较完就得到结果。这种符号形式是比较符合计算机的。

所以我们平时用的是中缀表达式；除此之外还有前缀表达式和后缀表达式，不同的计算机算法都会用到它们。下面看什么是前缀表达式，以及怎样把中缀表达式变成前缀表达式。

### 由中缀表达式构造前缀表达式

**27:02**

首先根据中缀表达式构建一棵树：根节点是运算符，子节点是命题变元，也就是一棵命题表达式树，按照它的括号和连接方式来构建。

在这个例子里，最外面这一层的符号是蕴含 \(\to\)，紧接着是否定 \(\neg\)，然后是析取 \(\vee\)。要把它转成前缀形式，做深度优先遍历即可：先遍历到 \(\to\)，把蕴含符号写在前面对应位置；下一个节点是 \(\neg\)；然后是 \(\vee\)；接着是 \(P\)，再是 \(Q\)；\(\vee\) 这一部分处理完之后是 \(r\)。这样就得到了前缀表达式 \(\to \neg \vee P Q r\)。

### 用栈计算前缀表达式

**28:24**

前缀表达式同样用栈的形式来求值：把它放在一个栈上，然后去计算它。计算时先取出最上面的符号，然后取后面的操作数。例如取到析取 \(\vee\) 时，它的两个操作数是 \(P\) 和 \(Q\)，于是先计算 \(P \vee Q\)；接着取到否定词 \(\neg\)，计算否定；把这个值放到它的左边，然后再 pop 出 \(r\)，作为右边的操作数。对计算机的栈操作来讲，这样是非常方便的。

### 后缀表达式及其栈求值

**29:07**

当然还有另一种反过来的形式，就是后缀表达式。后缀表达式是反着来的：同样是深度优先，但先从 bottom up，先把下面的节点记进来。例如先记 \(P\)，再记 \(Q\)，紧接着记它们的父节点析取 \(\vee\)，然后是否定词 \(\neg\)，然后是 \(r\)，最后记最上面的 \(\to\)。

后缀表达式同样可以用栈来做：先 pop 出 \(P\)，再 pop 出 \(Q\)，这两个都是参数，然后 pop 出一个运算符，把参数代入这个运算符计算；计算完之后继续往这边 pop，pop 出否定词，那个结果就变成参数，再做否定；否定之后取出 \(r\)，再取出它上面最后的符号，和左边这一坨东西一起完成最后的运算。所以对计算机来讲，后缀和前缀表达式可以用栈更好地实现整个计算过程。

### 为什么命题逻辑不足以表示程序

**31:10**

假设这是我们今天学的这个程序，把它变成命题逻辑表达式，它会写成什么样子？比如 \(a\) 是布尔类型，\(b\) 是整数类型，\(x\)、\(y\) 是 int32 的赋值，那么一次赋值就涉及 32 个 bit，每一个 bit 都要用一个命题变量来表示。从第 0 位到第 31 位，每一位的操作都要写出来，这还不排除进位操作。

所以，用命题逻辑表达式来表示程序、并且用求解器求解，对于复杂程序基本上是不可行的：整个表达式会非常复杂，导致求解器直接卡住、死机。

原因是什么？原因是命题逻辑表达式只能表达 true 或者 false，只能表达命题，它的表达空间非常有限：只能把 0 和 1 这两种语义映射成 true 和 false，表达能力有限，或者说表达能力很弱。

### 从命题逻辑到谓词逻辑

**32:56**

所以命题逻辑还不够高级。我们一般把命题逻辑表达式叫做零阶逻辑，它的阶数比较低。如果要化简一个对整个程序的命题逻辑表达，就需要引入新的逻辑。

这种逻辑就是谓词逻辑，它比命题逻辑更高阶。命题逻辑也叫零阶逻辑，谓词逻辑则叫一阶逻辑，相当于在原来基础上又上了一级台阶。

### 谓词、个体词与论域

**33:40**

要有更充分的表达能力，就需要引入新的表达方法，这种方法叫做谓词。什么是谓词？它可以用来形容一个个体。举个例子，比如“Tom 比 Jerry 强壮”，这里的“强壮”就是一个谓词；Tom 和 Jerry 是两个个体，我们管它们叫个体词。

这两个个体所属的范围叫论域。比如这里的论域，就是这张图里面的猫是 Tom、小不点是 Jerry。

**34:33**

这就是谓词的概念。可以认为它有点像语文里面说的形容词，用来形容或描述一个个体词的性质，或者两个个体之间的关系。

我们管 Tom 和 Jerry 叫个体常项：常项有具体的含义，就是图中这两个具体的人物。stronger 也有具体含义，表示 Tom 比 Jerry 强壮，这样的词我们叫谓词常项。

**35:18**

谓词实际上是把个体词、或者个体词之间的关系变成 true 或 false。比如“Tom 比 Jerry 强壮”在这张图里面就是真，那么它就是一个命题。

所以一个谓词就是一个命题。可以说它输入的是个体词，返回的是一个命题。接下来看 stronger。

### 谓词的元数

**35:57**

stronger 配了两个参数，我们管它叫二元谓词；此外也有一元谓词、三元谓词。谓词逻辑更高级的地方，在于它把个体词变成一个命题，也就是 true 或 false。有二元谓词、三元谓词、一元谓词，那有没有零元谓词呢？

零元谓词其实就是命题变元——一个命题逻辑变元本身就是一个命题。所以说，如果抛开常项来讲，我们可以用变项来表示。

### 谓词变项与个体变项

**36:59**

比如 \(P(x_1, \dots, x_n)\)，\(x_1\) 到 \(x_n\) 我们叫个体变项，\(P\) 叫谓词变项，它可以表示任何谓词。\(x_1\)、\(x_2\) 则表示论域里面任意的个体。

这就是一个 \(n\) 元谓词。再比如 \(7 = 5\)，数学里这个等号表示 7 是否等于 5，那么 7 是不是等于 5 呢？这就是一个二元谓词——等号，它返回 true 或 false。在这里它返回 false，因为 7 不等于 5，所以这是一个错误的命题。

**37:54**

对于没有具体含义的谓词，我们叫它谓词变项；对于没有具体含义的个体词的指代，叫个体变项。引入谓词以后，我们可以用它形容一个个体词的特征、特点，从而把之前那个程序进一步化简。

比如 \(x_1\)，以前是由 000001 这样的 32 个命题常项组成的，现在就可以直接写成 \(x_1 = 1\)，也就是“\(x_1\) 是否等于 1”。这里 \(x_1\) 是个体变项，1 是个体常项，等号是一个谓词。

**38:46**

因为我们有论域，就可以把任何一个状态定义成一个个体词；同时有谓词可以描述论域里面个体词的性质以及它们之间的关系。因此我们引入了一个等号符号，用来描述个体词和一个常项的关系：\(x_1 = 1\)，\(x_2 = 0\)，并且 \(x_4 = 1\)，并且 \(x_5 = 0\)，这些还没有变。

### 引入函数

**39:16**

我们能不能进一步化简？可以引入一个函数。因为刚才这些东西是一个复杂的表达式，就可以有一个新的概念叫函数。谓词也可以看成一个特殊的函数，它把个体词映射成命题。

那函数是什么？函数是把个体词直接映射成个体词。比如它输入一个或多个个体词，返回的是一个个体词，它的返回值是个体词。举个例子，定义一个函数 best friend。

**39:56**

比如海绵宝宝的 best friend 实际上是派大星。这就是一个函数，输入是个体词，返回也是个体词。那这个等号是什么？是谓词，等号是谓词。这就是函数的概念。

左边 best friend 这样的一个函数本身不是一个命题，因为它返回的其实是个体词；但是整个这一个是一个命题。

### 函数、谓词与连接词的区别

**40:59**

因为它把返回的个体词和另一个个体词用谓词连接起来，所以整个表达式本身是一个命题。函数返回的是个体词，不是命题，因此不能用命题联结词去连接函数；函数的输入参数也只面向个体词，不是面向命题。命题不是个体词，而是数理逻辑中的 statement，即判断其为 true 还是 false，这是最开始讲的概念。true/false 是命题的语义。若一个对象输入个体词、返回命题，就称它为谓词。这里必须作区分：这不是编程语言中的函数，而是谓词逻辑中的函数；它输入个体词，返回的也是个体词，因此称为函数。输入和返回值决定了一个对象到底是函数还是谓词。之前学过连接词：连接词的参数可以是命题，返回值也是命题，例如合取、析取、否定、蕴含和等价。这张表回答了刚才两位同学提出的关系问题。

### 零阶逻辑、数论与 ITE 函数

**43:09**

这些性质决定了连接符到底是连接词、谓词还是函数。举例来说，命题逻辑是零阶逻辑，比一阶逻辑低级，所以命题逻辑一定是一个特殊的谓词系统。它没有等号，它的谓词就是零元谓词，如 P、Q、R，它也没有函数。数论也是一个谓词系统：它有等号，大于、小于这类关系形成的就是谓词；加减乘除就是函数；个体词就是数论中的数，论域就是整个数的取值范围。

有了函数之后，可以定义新的函数。例如定义 ITE 函数：如果 a 为 true，就取 x1，否则取 x2。有些自然语言或编程语言中也有这个函数。这样可以把左边的命题逻辑表达式直接写成函数，不必每一项都写成谓词或命题形式。

### 用 ITE 与 sum 函数表达约束

**44:32**

直接写函数：\(x_3 = ITE(A, x_1, x_2)\)，\(y_6 = ITE(B, y_4, y_5)\)，这能推出来。同时还有一个函数，对于这个画面，命题逻辑基本上很难写出来，因为它要写非常长。有了函数之后，可以定义一个新函数 \(sum(x_6, y_6)\)，它返回 x6 和 y6 的和。

接下来要说：现在有了不同的变量，这个式子想证明什么？证明对于所有的个体变元，如果 \(x_1=1\)、\(x_2=0\)、\(y_4=1\)、\(y_5=0\)，如果这个成立，并且 \(x_3\) 等于这个函数、\(y_6\) 等于这个函数，就一定能推出 \(x_3\) 和 \(y_6\) 它们的和大于零。那么如何表示对所有这样的输入值它都可以成立？

### 量词：全称量词

**46:00**

这里需要引入一个新概念：量词。量词描述个体词在论域中的取值范围。有两个重要的量词，其实就两个。第一个叫全称量词，用符号 \( \forall x \) 表示。它的意思是：对于整个论域中的所有元素（member），它们都满足我的谓词。

举例来说，这张图里我要说所有玩具长得都像 Jerry。Jerry 在猫捉老鼠中跑到玩具店躲起来，里面真有一个是它的本尊；对 Tom 来讲，就是对所有 x，x 都满足这个谓词。这个谓词就是“长得像 Jerry”。全称量词后面跟着的作用域称为辖域，量词的辖域就是它后面的部分；这里任意 x 的辖域就是后面，然后这个叫约束变元。

### 全称量词的空论域规则与存在量词

**47:18**

对于量词约束的变元叫约束变元。例如 \( \forall x (mouse(x)) \)，这个本身是一个命题，因为 mouse 是谓词。对于任意 x，是否这个 x 都是 mouse，这个式子就是 false，因为图中有大象把自己画成了 Jerry 的形式。如果论域是空，有一个规则：\( \forall x P(x) \) 为 true。第二个量词叫存在量词。存在量词是说在所有论域中存在一个个体词，满足某个谓词的性质。

### 存在量词、空论域与辖域

**48:04**

刚才的意思就是，存在量词写作 \( \exists x \)，即存在一个 x，x 是 Jerry。在这张图中，存在一个 x 满足这个谓词。这里如果写成存在一个 x，x 是大象，在所有图中这就是 true，因为真的存在一个 x 是大象。如果论域是空，也是规则：这个式子就是 false，正好和全称量词相反。

量词实际上有很多规则。例如 \( \exists x \forall y (x \le y) \)。这里 x 和 y 都叫约束变元。蓝颜色框是 \( \exists x \) 的辖域，红颜色框是 \( \forall y \) 的辖域；对于 \( \exists x \forall y (x \le y) \)，它的辖域永远跟着量词后面。

### 量词的作用域

**49:28**

就是作用域。对于 \(\exists x P(x) \lor Q(x)\) 这样的式子，\(x\) 的作用域，除非显式加括号，否则 \(x\) 只作用在 \(P(x)\) 上。也就是说，\(P(x)\) 中的 \(x\) 是约束变元，而 \(Q(x)\) 中的 \(x\) 是自由变元。有了这样的式子之后，我们直接看例子。

### 个体变元、自由变元与量词的论域

**52:11**

\(x_1\) 是一个个体变元。对于所有的 \(x\)，如果它等于 0，那么它就会满足下一个式子；这里也是一个函数。\(x\) 是一个个体变元；如果它没有被量词约束，就是自由变元。要正儿八经地描述它，就要强调加一个量词。加了这个量词之后，这句话的意思是：整个式子里面，这个等于 0 的 \(x\) 表示论域里面的任意一个个体。\(\forall x\) 并没有在式子中显式显示论域，这是什么意思呢？比如论域是自然数，那么 \(\forall x\) 就表示对所有的自然数，也就是对论域这个范围中的所有值。它没有写出“属于”某个论域；在数理逻辑里面，不写这种“属于”的符号。
