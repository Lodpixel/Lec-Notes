### 回顾：命题逻辑的基本构成

**05:51**

上节课讲到，命题逻辑可以看成程序和计算机之间的桥梁。如果要验证一个程序，就需要先把程序以及它的正确性要求转换成命题逻辑能够表达的形式。

上节课主要建立了命题逻辑的基本框架：

- 用命题变量表示简单命题或原子命题，通常用大写字母 P、Q 等表示；
- 用命题联结词把命题组合起来；
- 用真值表说明联结词的语义；
- 用合式公式（well-formed formula，WFF）规定哪些表达式在语法上是合法的；
- 研究一组联结词是否足以表达所有可能的布尔函数。

**06:51**

命题逻辑本身是一个数学系统。要定义一个数学系统，首先需要定义它所使用的语言和变量。命题变量表示一个命题；命题变量之间还需要进行运算，因此需要定义命题联结词。

本课程使用的五种基本联结词是：

- 否定：¬；
- 合取：∧，表示“且”；
- 析取：∨，表示“或”；
- 蕴含：→；
- 双条件或等价：↔。

例如，P → Q 表示“如果 P 成立，那么 Q 成立”。这些符号和命题组合起来以后，会形成更复杂的命题逻辑表达式。

**11:27**

联结词和命题组合后表达的含义叫作语义。可以把一个联结词看成一个函数：它接收一个或多个真值作为输入，再返回一个真值。真值表就是描述这种输入与输出关系的一种方式。

如果一个联结词只连接一个或两个命题变量，那么含义比较直接；当一个联结词表达式包含三个、四个甚至更多变量时，就需要用明确的语法规则规定表达式如何构造。合式公式正是为此定义的。

合式公式的定义是递归的：

1. 每个原子命题都是合式公式；
2. 如果 A、B 是合式公式，那么 ¬A、A ∧ B、A ∨ B、A → B、A ↔ B 也都是合式公式；
3. 除上述规则外，其他形式都不是合式公式。

### 命题逻辑的完备性

**17:36**

接下来回顾为什么常用这五种联结词，以及它们是否足以表达所有命题逻辑函数。

设 g 是一个 n 元布尔函数。它接收 n 个真值作为输入，输出只能是 true 或 false。我们要证明：对于任意这样的 g，都存在一个合式公式，使它在每一种输入赋值下都和 g 具有相同的真值。

这实际上是在把一个问题形式化：先把函数或问题写成数理逻辑的语言，再研究是否能够用规定的联结词表达它。

#### 二元函数的构造

**18:52**

先看 n = 2 的情况。设两个命题变量为 P、Q，它们共有四种真值赋值：

- P 为 true，Q 为 true；
- P 为 true，Q 为 false；
- P 为 false，Q 为 true；
- P 为 false，Q 为 false。

每一行的输出都可以独立取 true 或 false，因此一共有：

~~~text
2^4 = 16
~~~

个不同的二元布尔函数。

构造与某个函数等价的合式公式时，可以根据真值表中输出为 true 的行来构造。对每一行：

- 如果某个变量在这一行取 true，就在对应条件中写这个变量；
- 如果某个变量取 false，就写它的否定；
- 同一行中的条件用合取连接。

例如，P 为 false、Q 为 true 的那一行，对应的条件就是：

~~~text
¬P ∧ Q
~~~

如果真值表中有多行输出为 true，就把这些行对应的条件用析取连接。例如，若第 i 行对应的条件是 M_i，那么可以写成：

~~~text
M_1 ∨ M_2 ∨ ... ∨ M_k
~~~

这样构造出的表达式只在原真值表输出为 true 的那些行上为 true，因此与原函数等价。

也可以反过来根据输出为 false 的行构造。若某个函数所有行都为 false，可以用：

~~~text
P ∧ ¬P
~~~

表示矛盾；若所有行都为 true，可以用：

~~~text
P ∨ ¬P
~~~

表示永真。

**24:47**

#### 推广到 n 元函数

对任意 n 元函数，构造方法和二元情形完全相同。设变量为 P₁、P₂、……、Pₙ，真值表一共有 2ⁿ 行。

假设函数在真值表中有 k 行输出为 true。对第 i 行，定义一个合取项 M_i：

- 第 j 个变量在该行取 true 时，取 Pⱼ；
- 第 j 个变量在该行取 false 时，取 ¬Pⱼ；
- 将这 n 个文字用 ∧ 连接。

然后把所有输出为 true 的行对应的合取项用 ∨ 连接：

~~~text
g(P₁, ..., Pₙ) ≡ M₁ ∨ M₂ ∨ ... ∨ Mₖ
~~~

对每一种赋值，只有与当前行完全匹配的合取项会为 true，其他合取项都会为 false。因此，整个表达式的真值和 g 完全一致。

这说明，命题逻辑中的基本联结词足以表达任意有限元的布尔函数，五种联结词构成一个完备的联结词集合。

### 为什么常用五种联结词

**30:06**

从表达能力来看，五种联结词并不是都不可替代。例如：

~~~text
P → Q ≡ ¬P ∨ Q

P ↔ Q ≡ (P → Q) ∧ (Q → P)
       ≡ (¬P ∨ Q) ∧ (¬Q ∨ P)

P ∧ Q ≡ ¬(¬P ∨ ¬Q)
~~~

因此，只要保留否定和析取，就可以表示蕴含、双条件和合取。类似地，只使用某些单一的逻辑门也可以构造出其他逻辑运算。

但在实际使用数理逻辑时，否定、合取、析取、蕴含和双条件是最常见、最直观的五种关系：

- 否定表示把一个命题的真假反转；
- 合取表示两个命题同时成立；
- 析取表示至少一个命题成立；
- 蕴含表示条件和结论之间的关系；
- 双条件表示两个命题相互等价。

所以课程采用五种联结词，主要是为了表达方便，而不是因为其他联结词无法由它们表示。

### 用命题逻辑形式化二皇后问题

**35:23**

接下来用命题逻辑形式化一个简单问题：二皇后问题。

问题是：在一个 2×2 的棋盘上放置两个皇后，使任意两个皇后都不在同一行、同一列或同一条对角线上。

要证明的结论是：二皇后问题无解。也就是说，在 2×2 棋盘上放置两个皇后时，两个皇后一定会共享一行、一列或一条对角线。

**39:34**

把棋盘抽象成一个有状态的对象。棋盘有四个位置，每个位置只有两种状态：有皇后或没有皇后。因此，可以用四个命题变量表示四个位置：

- P₁ 为 true：第一个位置有皇后；
- P₁ 为 false：第一个位置没有皇后；
- P₂、P₃、P₄ 同理。

首先表示“任意两个位置不能同时有皇后”的限制：

~~~text
¬(P₁ ∧ P₂) ∧ ¬(P₁ ∧ P₃) ∧ ¬(P₁ ∧ P₄)
∧ ¬(P₂ ∧ P₃) ∧ ¬(P₂ ∧ P₄) ∧ ¬(P₃ ∧ P₄)
~~~

在 2×2 棋盘中，任意两个不同位置的皇后都会互相攻击，因此六个位置对都需要排除。

接下来表示“恰好放置两个皇后”。六种可能的放置方式可以写成：

~~~text
(P₁ ∧ P₂ ∧ ¬P₃ ∧ ¬P₄)
∨ (P₁ ∧ P₃ ∧ ¬P₂ ∧ ¬P₄)
∨ (P₁ ∧ P₄ ∧ ¬P₂ ∧ ¬P₃)
∨ (P₂ ∧ P₃ ∧ ¬P₁ ∧ ¬P₄)
∨ (P₂ ∧ P₄ ∧ ¬P₁ ∧ ¬P₃)
∨ (P₃ ∧ P₄ ∧ ¬P₁ ∧ ¬P₂)
~~~

问题是否有解，就变成检查“放置条件”和“不互相攻击条件”的合取是否可满足。如果两者的合取恒为 false，就证明了二皇后问题无解。

**46:30**

如果直接用真值表检查，四个变量一共有：

~~~text
2^4 = 16
~~~

行。每一行都要代入整个表达式进行计算。

计算量取决于两个因素：

1. 变量数量决定真值表有多少行；
2. 表达式本身的复杂度决定每一行需要计算多少步，复杂度包括联结词和括号的数量。

因此，即使变量数量不多，如果表达式很长，逐行计算仍然会很麻烦。下一节将讨论如何用等价变换简化表达式。

## 2026 年 9 月 20 日｜第 2 节回放

### 联结词的优先级

**04:37**

上一节最后留下的问题是：能不能简化命题逻辑表达式，减少括号和计算量？

首先要约定联结词的优先级。按照本课的约定，从高到低依次是：

1. 否定 ¬；
2. 合取 ∧；
3. 析取 ∨；
4. 蕴含 →；
5. 双条件 ↔。

优先级会直接影响表达式的含义。例如，表达式 P ∨ Q ∧ R，如果合取优先级高，就解释为：

~~~text
P ∨ (Q ∧ R)
~~~

如果错误地把析取看作优先，就会解释成：

~~~text
(P ∨ Q) ∧ R
~~~

令 P 为 true、Q 为 false、R 为 false。前一种解释的结果是 true，后一种解释的结果是 false。因此，没有明确优先级时，两个表达式的语义可能完全不同。

在二皇后问题中，¬(P₁ ∧ P₂) 表示 P₁ 和 P₂ 不能同时为 true；如果写成 ¬P₁ ∧ P₂，含义就变成 P₁ 为 false 且 P₂ 为 true，两者不是一回事。

**08:44**

命题逻辑和 C、C++、Python 等编程语言一样，也需要规定运算符优先级。否定的优先级最高，其次是合取、析取、蕴含，最后是双条件。实际书写时，如果表达式容易产生歧义，应该主动加括号。

### 结合顺序

**10:09**

除了优先级，还要规定连续运算的计算顺序。按照本课的约定，连续出现的同类运算默认从左到右结合。

但蕴含不满足结合律，因此：

~~~text
(P → Q) → R
~~~

和：

~~~text
P → (Q → R)
~~~

一般不等价。涉及多个蕴含词时，必须用括号明确表达式的结构。

这可以用 Tom、Jerry 和奶酪的例子理解：连续出现的两个“如果……那么……”可能对应不同的因果关系。把它们简单地从左到右连接起来，和先把右侧的条件组合起来，表达的意思并不相同。

合取、析取和双条件在相应条件下满足结合律；但不能把这个性质推广到蕴含。

### 等价与等价定律

**14:41**

如果两个合式公式在所有真值赋值下都具有相同的真值，就称它们等价，记作 A ≡ B。

等价关系可以用双条件表示：如果 A、B 等价，那么 A ↔ B 在所有赋值下都为 true，也就是一个永真式。

常用的等价定律包括以下几类。

#### 德·摩根律与双重否定律

~~~text
¬(P ∧ Q) ≡ ¬P ∨ ¬Q

¬(P ∨ Q) ≡ ¬P ∧ ¬Q

¬¬P ≡ P
~~~

第一条的直观含义是：“P 和 Q 不同时成立”等价于“P 不成立或 Q 不成立”。第二条表示：“P 或 Q 不成立”等价于“P、Q 都不成立”。

#### 蕴含消去

~~~text
P → Q ≡ ¬P ∨ Q
~~~

蕴含只有在前件为 true、后件为 false 时为 false，而 ¬P ∨ Q 恰好具有相同的真值规律。因此，在化简表达式时，常常先把蕴含词替换成否定和析取。

#### 结合律与交换律

合取、析取和双条件满足结合律和交换律。例如：

~~~text
(P ∨ Q) ∨ R ≡ P ∨ (Q ∨ R)
(P ∧ Q) ∧ R ≡ P ∧ (Q ∧ R)

P ∨ Q ≡ Q ∨ P
P ∧ Q ≡ Q ∧ P
P ↔ Q ≡ Q ↔ P
~~~

蕴含不满足交换律，也不满足结合律。P → Q 与 Q → P 通常不等价。

#### 幂等律、同一律和零律

~~~text
P ∨ P ≡ P
P ∧ P ≡ P

P ∨ F ≡ P
P ∧ T ≡ P

P ∨ T ≡ T
P ∧ F ≡ F
~~~

其中 T 表示 true，F 表示 false。

#### 互补律与蕴含的特殊情形

~~~text
P ∨ ¬P ≡ T
P ∧ ¬P ≡ F

P → P ≡ T
P → F ≡ ¬P
T → P ≡ P
F → P ≡ T
P ↔ ¬P ≡ F
~~~

P ∨ ¬P 是永真式，P ∧ ¬P 是矛盾式。这些规律可以通过真值表证明，也可以作为后续化简时直接使用的等价定律。

#### 分配律与吸收律

~~~text
P ∨ (Q ∧ R) ≡ (P ∨ Q) ∧ (P ∨ R)

P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R)

P ∨ (P ∧ Q) ≡ P
P ∧ (P ∨ Q) ≡ P
~~~

当一个表达式中有很多变量和括号时，可以使用分配律逐步展开，再结合交换律、结合律、互补律等继续化简。这些规则不仅用于手算，也会用于计算机对程序和逻辑表达式进行标准化处理。

### 用等价变换化简二皇后公式

**26:59**

回到上一节的二皇后问题。放置条件表示“恰好选择两个位置”，限制条件表示“任意两个位置不能同时有皇后”。把两者合取后，目标是证明整个表达式等价于 F。

首先可以依据优先级去掉一部分不必要的括号，再用德·摩根律把否定移入括号内部。接着使用交换律、结合律和分配律，把具有相同变量的项放到一起。

例如，在展开过程中会出现：

~~~text
P ∧ ¬P
~~~

它等价于 F。只要某个分支中出现这个矛盾，而整个表达式的各个分支又通过合取连接，就可以继续把该分支化为 F。最终，整个“放置两个皇后且不互相攻击”的表达式等价于 F，因此问题无解。

这个例子说明，除了列真值表，还可以直接使用等价定律化简表达式。对于变量更多、公式更长的问题，等价变换通常比完整真值表更有可操作性。

### 用等价定律证明公式

**29:22**

课堂上用等价变换练习了两个常见结论。

第一个是逆否命题：

~~~text
P → Q
≡ ¬P ∨ Q
≡ Q ∨ ¬P
≡ ¬¬Q ∨ ¬P
≡ ¬Q → ¬P
~~~

因此：

~~~text
P → Q ≡ ¬Q → ¬P
~~~

第二个结论是：

~~~text
P → (Q → R) ≡ (P ∧ Q) → R
~~~

证明如下：

~~~text
P → (Q → R)
≡ ¬P ∨ (¬Q ∨ R)
≡ ¬P ∨ ¬Q ∨ R
≡ ¬(P ∧ Q) ∨ R
≡ (P ∧ Q) → R
~~~

这类证明不需要把所有变量情况列成真值表，而是直接按照已经证明过的等价定律进行变换。

### Matching problem：用命题逻辑证明无解

**39:10**

最后讨论一个 matching problem。设有三个人：Tom、Jerry 和小不点；可分配的食物有鸡肉和牛奶。每个人只能选择一种食物，并且不允许两个人共享同一种食物。

课堂原音中对鸡肉的英文称呼有过口误，下面统一用“鸡肉”表示课件中的 chicken。

定义三个命题变量：

- P₁：Tom 选择鸡肉；
- P₂：Jerry 选择鸡肉；
- P₃：小不点选择鸡肉。

如果 Pᵢ 为 false，就表示第 i 个人选择牛奶。小不点只能吃鸡肉，所以：

~~~text
P₃
~~~

同时，不能有两个人同时选择鸡肉：

~~~text
¬(P₁ ∧ P₂) ∧ ¬(P₁ ∧ P₃) ∧ ¬(P₂ ∧ P₃)
~~~

Tom 和 Jerry 也不能同时选择牛奶，因此还要加入：

~~~text
¬(¬P₁ ∧ ¬P₂)
~~~

每个人“要么选鸡肉、要么选牛奶”的条件可以写成 Pᵢ ∨ ¬Pᵢ，但这对每个变量都是永真式，所以可以省略。

整个问题的命题表达式为：

~~~text
Φ = P₃
    ∧ ¬(P₁ ∧ P₂)
    ∧ ¬(P₁ ∧ P₃)
    ∧ ¬(P₂ ∧ P₃)
    ∧ ¬(¬P₁ ∧ ¬P₂)
~~~

使用德·摩根律后：

~~~text
Φ ≡ P₃
    ∧ (¬P₁ ∨ ¬P₂)
    ∧ (¬P₁ ∨ ¬P₃)
    ∧ (¬P₂ ∨ ¬P₃)
    ∧ (P₁ ∨ P₂)
~~~

因为 P₃ 为 true，所以：

~~~text
P₃ ∧ (¬P₁ ∨ ¬P₃) ≡ P₃ ∧ ¬P₁
P₃ ∧ (¬P₂ ∨ ¬P₃) ≡ P₃ ∧ ¬P₂
~~~

这会迫使 P₁、P₂ 都为 false。但最后还有 P₁ ∨ P₂，矛盾由此产生：

~~~text
¬P₁ ∧ ¬P₂ ∧ (P₁ ∨ P₂) ≡ F
~~~

因此 Φ 等价于 F，不存在满足所有约束的分配方案。

### 永真式与矛盾式

**48:59**

如果一个命题逻辑表达式在任意变量赋值下都为 true，就叫永真式（tautology）；如果它在任意赋值下都为 false，就叫矛盾式（contradiction）。

例子：

~~~text
P ∨ ¬P：永真式
P ∧ ¬P：矛盾式
P ∧ F：矛盾式
P ∨ T：永真式
~~~
